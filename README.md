# OOPS · 원터치 서바이벌

배틀그라운드 PC를 참고한 OOPS 클랜의 브라우저 회피 게임입니다. 모바일 세로 화면과 PC에서 실행됩니다. 외부 서비스·로그인·API 키·게임 서버가 필요하지 않습니다.

**먼저 [수동 업로드·배포 안내](docs/DEPLOY_KO.md)를 읽으세요.** ZIP을 압축 해제하고 이 폴더 안의 파일을 GitHub에 올리면 됩니다. GitHub 업로드와 Vercel 배포는 사용자가 직접 진행합니다.

## 플레이

- 캐릭터는 하단에서 계속 달립니다. OOPS 버튼 터치/클릭 또는 스페이스바 한 번으로 이동 방향을 바꿉니다.
- 화면 끝에서는 방향을 유지한 채 제자리에서 달립니다. 버튼을 누르면 반대 방향으로 출발합니다.
- 블루칩 2개 → 첫 피격 1개 → 두 번째 피격 0개(생존) → 세 번째 피격 사망. 사망 위치에 전리품 상자를 남깁니다.
- 장비 3종을 자유롭게 선택합니다. 외형만 달라지며 판정과 능력치는 같습니다.
- 탭을 떠나면 자동으로 멈춥니다. 돌아와 `이어 하기`를 눌러 3초 카운트다운 후 재개합니다.
- 이 기기·브라우저의 개인 최고 기록, 장비, 소리 설정을 저장합니다. 전체 클랜 랭킹/코인 지급/보상 기능은 없습니다.

## 주요 기본값

| 항목 | 기본값 |
|---|---|
| 게임 내부 좌표 | 400 × 600, 모든 기기 동일 |
| 상대 단위 | 1 = 내부 좌표 10; 플레이어 크기 5 |
| 플레이어 속도 | 160 / 초, 게임 중 일정 |
| 경계 | 장비 전체 범위 50 + 좌우 추가 여백 5 |
| 첫 장애물 생성 | 시작 후 1.4초, 상단 바깥에서 출발 |
| 장애물 생성 간격 | 0.85초; 시간에 따라 증가하지 않음 |
| 낙하 배율 | `1.1 ** (생존시간 / 30)` |
| 대각선 범위 | 수직에서 -15°~+15°, 생성 후 방향 유지 |
| 피격 후 무적 | 1.2초 |
| 맵 주기 | 60초 |
| 폭풍 시작 | 360초; 이후 계속 유지 |
| 카운트다운 | 3초 |
| 최고 기록 | localStorage, 개인 로컬 기록 |

| 장애물 | 상대 크기 | 기본 속도/초 | 등장 가중치 |
|---|---:|---:|---:|
| 레드존 미사일 | 5 | 155 | 1 |
| UAZ | 8 | 140 | 1 |

크기는 투명 여백을 잘라낸 이미지의 가장 긴 변에 적용합니다. 가로세로 비율을 유지합니다. 기본 속도는 이동 경로 방향의 속도이며 세로 성분은 `speed * cos(angle)`입니다. 모든 장애물은 같은 연속 배율을 적용합니다. 안전한 생성 후보가 없으면 그 회차를 건너뛰며, 부족분을 몰아서 생성하지 않습니다.

## 로컬 실행

Node.js 20 이상을 설치한 컴퓨터에서 이 폴더를 터미널로 열고 실행하세요.

```sh
npm install
npm run dev
```

터미널에 표시되는 `http://localhost:4173`을 브라우저에서 여세요. 이 주소는 **자신의 컴퓨터에서만 쓰는 로컬 주소**입니다. `index.html`을 파일 탐색기에서 더블클릭하는 방식은 ES 모듈 로딩 때문에 지원하지 않습니다.

```sh
npm test
npm run build
npm run preview
```

빌드 결과는 `dist/`입니다. 런타임/빌드 의존성은 없습니다. npm install은 제공된 잠금 파일을 확인합니다.

## 구현 상세

프레임 수가 아닌 `performance.now()`의 경과 초를 사용합니다. 장애물 이동에는 지수 속도의 적분을 적용하며, 1/120초 이하의 로직 구간과 상대 이동 선분 충돌 판정을 함께 사용하여 고속 관통을 막습니다. 렌더링은 requestAnimationFrame과 최대 DPR 2를 사용합니다. 맵·폭풍·무적·난이도는 같은 생존 시간으로 계산하며 일시정지 동안 전부 정지합니다.

생성 후보의 플레이어 높이 도착 시간과 가로 위치를 예상하고, 같은 시각대 장애물의 위험 구간을 합쳐 충분히 넓은 회피 공간과 이동 가능한 거리가 남는지 확인합니다. 무작위 경로 전체의 절대적인 회피 가능성을 증명하는 알고리즘은 아니며, 초기 막힘과 동시 전폭 봉쇄를 줄이는 방식입니다. 초장기 생존에서는 요청된 무제한 지수 가속 때문에 난이도가 매우 높아집니다.

사운드는 첫 사용자 입력에서 AudioContext를 활성화하며, 작은 합성 효과음과 낮은 비/천둥 음량을 사용합니다. 음소거 설정은 저장됩니다. 장비와 기록은 주소(origin)별 저장이므로 Preview 주소와 Production 주소, 다른 브라우저·기기 사이에 공유되지 않습니다. 시크릿 모드·저장소 삭제·브라우저 저장 제한에서는 보존이 제한됩니다.

공식 PUBG 리소스를 그대로 제공하는 프로젝트가 아닙니다. 맵과 차량의 공식 참고 페이지를 바탕으로 만든 자체 생성 일러스트와 장비의 시각적 해석이 포함되어 있습니다. 일부 장비는 세부 실루엣과 시점이 실제 게임과 다릅니다. 에셋 설명서를 확인하세요.
